# AI Passport · 额度星盘随身版

这是装在AI Passport上的随身消息与额度看板。Mac主客户端、同步助手和设备固件是三个不同的下载，请按用途选择。

| 下载 | 装在哪里 | 作用 | 入口 |
|---|---|---|---|
| Quota Orbit Mac主客户端 | Mac | 桌宠、菜单栏和星盘查看额度与公开消息；不要求购买Passport | [正式版本](https://github.com/koi-lee/quota-orbit/releases/latest) |
| Passport Mac同步助手0.2.0 | Apple芯片Mac | 把已登录Codex的个人额度交给已配对的Passport；无需安装Python | [助手预发布和安装说明](https://github.com/koi-lee/quota-orbit/releases/tag/passport-helper-v0.2.0) |
| Passport设备固件 | AI Passport硬件 | 显示公告、来信、角色、书灯并播放提示音 | [社区作品1250](https://ai-passport.folotoy.cn/plays/1250/) |

助手不会替换Mac主客户端；设备固件不能安装到Mac。GitHub的“Source code”自动归档对应这个Mac主客户端仓库，不是Passport固件源码。Passport固件目前在社区分发，本仓库此目录提供它的使用与展示文档。

## 第一次使用

1. 从社区安装固件会替换当前玩法，可能清除旧配置。手机连接屏幕当前显示的Starshore-…热点，使用屏幕密码；浏览器打开http://192.168.4.1，填2.4 GHz Wi-Fi并连接保存。“已同步·公开消息”表示成功。失败可重填；超时或换网时长按确定→设置→重新配网。
2. 上下键切换首页、来信、角色。首页确定看来信；来信确定显示小程序码，微信扫码进“星岸重置助手”；再按确定返回。角色短按确定点星，长按确定进设置。
3. 提示音默认关，开启后试听点按、预告、完成三类音。公开消息约每五分钟轮询；有效的新预告或完成公告响一次，首次同步、重复和旧消息不响。
4. 个人额度为可选功能：启动配套Mac助手，Mac登录Codex、两者同Wi-Fi。USB连接后先点电脑“连接设备”，等硬件启动，再硬件设置→连接Mac→确定允许。电脑点开始同步；角色页出现额度后可拔USB。Mac保持运行、唤醒及登录。暂停/退出停止推送，解除配对在硬件设置确认。

## 失败与恢复

| 状态 | 表示什么 | 如何继续 |
|---|---|---|
| 配网认证失败 | 未连接上家庭Wi-Fi | 本地核对Wi-Fi名/密码，重新提交；不是填写设备热点密码 |
| 配网超时 | 临时热点已关闭 | 长按确定→设置→重新配网 |
| 同步中断/来源过期 | 公告同步失败或来源不够新鲜 | 看读取时间，保留旧记录；设备继续重试，不能把旧公告当当前结果 |
| 个人额度未提供 | Codex未返回该窗口或尚未同步 | 不显示虚构百分比；检查Mac登录与同步状态 |
| 个人额度旧数据 | Mac暂停、休眠或连接中断 | 恢复Mac和助手；设备IP变化后需重新连接配对，自动发现暂未提供 |

## 验证与限制

正式应用9092dc72、社区版本2840已公开。已有用户验收覆盖三页、中文可读性、小程序扫码、USB配对、拔线后同Wi-Fi同步、连续点星和声音。预告/完成与重复/静音的受控回放通过；真实新公告的自然触发、长期休眠/断网、社区从零完整安装仍待验证。

助手仅当前Apple芯片Mac经过验证，未Developer ID签名/公证；Intel与其他系统未验收。登录凭据留在Mac，密钥留在用户本地；不要分享配对文件。示例图不代表当前公告或个人额度。
